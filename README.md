# ACCESS-AI_TECH-TITANS_HACKDAY1
AccessAI is an AI-powered accessibility platform that makes digital content more inclusive. It offers live captions, read page/selected text, AI assistance, accessibility scanning, large text, high contrast, easy reading, large cursor, focus mode, reduced motion, keyboard shortcuts, and file support.

AccessAI — Accessibility for Everyone ♿🤖

AccessAI is an AI-powered accessibility assistant designed to make websites and digital content easier to use for people with visual, hearing, motor, and cognitive impairments. It combines accessibility tools, AI assistance, and automated website scanning into a single, user-friendly platform.

🚀 Key Features

- 🎙️ Live Captions — Displays real-time captions when the AI speaks.
- 🔊 Read Page — Reads webpage content aloud with word-by-word highlighting.
- 📖 Read Selected — Reads only the text selected by the user.
- 🔍 AI Accessibility Scanner — Scans websites for potential accessibility issues.
- 🌐 Website Scan — Helps identify elements that may be difficult to access or understand.
- 🤖 AI Assistance Always Available — Provides AI-powered help whenever users need it.
- 💬 Talk to AccessAI — Allows users to interact with the assistant through voice.
- 📂 Import/Open Files — Allows users to open files from their device and access their content.
- 🔠 Large Text — Increases text size for improved readability.
- 🌓 High Contrast — Improves visibility for users with visual difficulties.
- 📚 Easy Reading — Simplifies the reading experience and improves content readability.
- 🖱️ Large Cursor — Makes the cursor easier to see and track.
- 🎯 Focus Mode — Reduces distractions and helps users focus on important content.
- 🧘 Reduce Motion — Minimizes animations and motion for a more comfortable experience.
- ⌨️ Keyboard Help & Shortcuts — Provides keyboard-based navigation and accessibility controls.

🎯 Our Goal

AccessAI aims to bridge the accessibility gap by bringing multiple assistive features into one platform. Instead of requiring users to rely on separate tools, AccessAI provides a centralized interface that adapts digital experiences to different accessibility needs.

Built with the vision of making technology more inclusive, usable, and accessible for everyone.
